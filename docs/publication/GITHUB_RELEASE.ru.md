# GUI OpenVPN [aka BasiliyWolf] v1.0.1

Графический клиент OpenVPN для Linux Mint и Ubuntu на C++17 и Qt 6.

## Возможности

- Управление профилями OpenVPN через NetworkManager: импорт `.ovpn`, подключение, отключение и переподключение.
- Авторизация с сохранением секретов через системное хранилище Keyring.
- Статистика сети, внешний IPv4, системный трей и журнал событий.
- Редактор маршрутов IPv4/IPv6 и режимов маршрутизации.
- Переключение русского и английского языка для основных элементов интерфейса.
- Экспериментальный запуск отдельных приложений в изолированном сетевом пространстве с ограничивающими правилами firewall.

## Установка

Скачайте `gui-openvpn-basiliywolf-1.0.1-Linux.deb` из Assets релиза, затем выполните:

```bash
sudo apt update
sudo apt install ./gui-openvpn-basiliywolf-1.0.1-Linux.deb
```

Приложение доступно в меню или командой `gui-openvpn-basiliywolf`.

## Совместимость и ограничения

Пакет предназначен для `amd64` и требует Qt 6, NetworkManager и дополнительные системные компоненты. В зависимостях присутствуют библиотеки Qt 6 `t64`, поэтому не все версии Mint/Ubuntu смогут установить данный DEB.

Известные ограничения: некоторые диалоги содержат смешанные RU/EN строки; определение VPN-интерфейса и статистика нуждаются в проверке; изолированный Kill Switch не прошёл независимые испытания на утечки DNS/IPv4/IPv6. Не рассматривайте его как гарантированную защиту.

Исходный код и дополнительные инструкции — в репозитории. Лицензия должна быть явно выбрана и опубликована автором до разрешения на дальнейшее распространение кода третьими лицами.
